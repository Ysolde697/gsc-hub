# Как запустить панель на ноутбуке

Около 20 минут, один раз. Дальше панель открывается в браузере по адресу
http://localhost:5173 всё время, пока включён ноутбук.

## 1. Поставить Docker Desktop

Скачайте с https://www.docker.com/products/docker-desktop/ (Windows или Mac),
установите и запустите. Дождитесь, пока в окне Docker появится «Engine running».

## 2. Распаковать архив

Распакуйте `gsc-hub.zip` в удобную папку, например `Документы/gsc-hub`.

## 3. Запустить

Откройте терминал в этой папке:

- **Windows:** откройте папку в Проводнике, щёлкните по адресной строке,
  наберите `cmd` и нажмите Enter.
- **Mac:** щёлкните по папке правой кнопкой → «Новый терминал по адресу папки».

Вставьте и нажмите Enter:

```
docker compose up -d --build
```

Первый запуск занимает 3–5 минут. Потом откройте http://localhost:5173.

## 4. Google-ключ для панели (один раз)

Панель попросит **Client ID** и **Client Secret**. Это ключ, через который
она заходит в ваши консоли. Создаётся бесплатно:

1. Откройте https://console.cloud.google.com/ под любым своим Google-аккаунтом
   и создайте проект (например `gsc-hub`).
2. Включите Search Console API:
   https://console.cloud.google.com/apis/library/searchconsole.googleapis.com → «Включить».
3. Google Auth Platform → **Audience** → тип **External**. Нажмите **Publish app**
   или добавьте в **Test users** почты всех консолей, которые будете подключать.
4. **Clients** → **Create client** → тип **Web application**.
   В **Authorized redirect URIs** добавьте ровно:
   `http://localhost:5173/auth/callback/google`
5. Скопируйте Client ID и Client Secret в панель и сохраните.

## 5. Подключить консоли

Нажмите **Connect Google account** и войдите в нужный аккаунт. Повторите для каждой
консоли. Google покажет предупреждение «приложение не проверено»: нажмите
«Дополнительно» → «Перейти на сайт gsc-hub». Это ваш собственный ключ, так и должно быть.

## Новое в этой версии

- **«Консоли: N из M»** в шапке: какие консоли участвуют в отчётах
  («Все», «Ни одной», «только эта»).
- **«Сайты: …»** в шапке: фильтр по группе сайтов. Группы настраиваются
  через «Настроить группы…» (например «Приоритет» — сайты, которые продвигаете).

## Остановить, обновить, перенести

- Остановить: `docker compose down` (данные сохранятся).
- Запустить снова: `docker compose up -d`.
- Все данные (подключённые консоли, группы, настройки) лежат в папке `data`.
  Чтобы перенести панель на сервер, достаточно перенести эту папку вместе с кодом.
